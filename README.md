# 🎓 Object-Oriented Programming Course (C++)

![C++](https://img.shields.io/badge/C++-17-blue)
![OOP](https://img.shields.io/badge/OOP-Core_Concepts-green)
![University](https://img.shields.io/badge/Course-AGH-lightgrey)

This repository contains a collection of C++ tasks developed as part of the *Object-Oriented Programming Language* course at AGH University of Krakow. Each project showcases key principles of OOP such as encapsulation, inheritance, polymorphism, abstraction, etc...

## Topics Covered

- Classes and Objects  
- Inheritance & Polymorphism  
- File I/O  
- Operator Overloading  
- Encapsulation and Abstraction  
- Templates and Exception Handling
- Introduction to UML

  And more...
